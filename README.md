# MAX Lite

Минималистичная Android-обёртка над веб-версией мессенджера MAX
(https://web.max.ru). Сделана вместо официального клиента, который требует
десятки разрешений. Здесь — только чат и обмен файлами.

## Приватность

- **Единственное разрешение — INTERNET.** (На Android 8–9 дополнительно
  WRITE_EXTERNAL_STORAGE для сохранения скачанного; на Android 10+ его нет.)
- **Блокировка телеметрии** — включена по умолчанию, перехватываются запросы
  к myTracker/top.mail.ru (трекеры VK), Яндекс.Метрике/AppMetrica,
  Google Analytics, Sentry и др. Список дополняется в настройках.
  Перехват работает и для запросов через service worker.
- **Камера, микрофон, геолокация** запрещены на уровне WebView — сайт не может
  их даже запросить. Следствие: звонки не работают (осознанно).
- **Safe Browsing отключён** — WebView не отправляет посещаемые URL в Google.
- **Сторонние cookies запрещены**, `allowBackup=false`, cleartext-трафик запрещён.
- Навигация заперта на доменах max.ru/oneme.ru; чужие ссылки открываются
  во внешнем браузере, а не внутри приложения.
- Ноль сторонних библиотек: ни AndroidX, ни Firebase, ни аналитики. Весь код —
  5 небольших Kotlin-файлов, всё можно прочитать глазами.

## Функционал

- Чат (вся веб-версия MAX как есть);
- Отправка файлов — системный пикер, без доступа приложения к хранилищу;
- Скачивание файлов в Downloads (обычные ссылки — через DownloadManager,
  blob: — через JS-мост);
- Настройки: переключатель телеметрии со счётчиком и логом заблокированного,
  свои домены блокировки, десктопный User-Agent, очистка cookies.

## Настройки — как открыть

- Долгое нажатие на иконку приложения → ярлык «Настройки», или
- долгое нажатие кнопки «Назад» внутри приложения.

## Ограничения

- **Нет push-уведомлений**: web push в WebView не работает, а FCM — это
  ровно та телеметрия Google, от которой ушли. Сообщения видны при
  открытом приложении.
- Нет звонков (камера/микрофон заблокированы намеренно).

## Сборка

Обычный Gradle-проект (AGP 8.5, Gradle 8.9, Kotlin 1.9): `./gradlew assembleDebug`
или открыть в Android Studio. Про сборку на Windows-ноде из этой VPS —
см. `DEV-SETUP.md` (`build-max`).
